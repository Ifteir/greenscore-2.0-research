# GreenScore 2.0

## Sustainability Assessment for Computing Devices

GreenScore 2.0 is a research project focused on developing a transparent
and balanced sustainability assessment approach for computing devices.

## Research Objective

The main objective is to explore how sustainability-related information
from different sources can be combined to evaluate computing devices
across multiple sustainability dimensions.

## Sustainability Dimensions

- Carbon Footprint
- Resource Circularity
- Energy Efficiency
- Social Responsibility

## Device Categories

- Laptops
- Desktops
- Enterprise Servers

## Research Approach

We plan to follow a hybrid approach using public sustainability data
and software-based measurements from accessible devices.

The research methodology includes:

1. Device selection
2. Data collection
3. Data preprocessing and validation
4. Sustainability scoring
5. Sensitivity analysis and evaluation
